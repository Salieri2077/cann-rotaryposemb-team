## 设计依据

- 排名按每点得分平均，不能只优化绝对耗时最大的点。优先降低中小规模的三角函数和调度成本，同时改善大任务搬运。
- 联合多项式复用约减结果和中间量，数学系数通过高精度拟合得到；保留 FP32 频率、角度及旋转计算。官方 A2/A3 不支持直接使用 SinCos，因此使用基础向量 API 实现。[推导与官方来源](sincos_design.md)。
- 对齐路径连续读写完整行，以 repeat stride 配对两半；非对齐路径保留 DataCopyPad。
- 多 token 合并三角计算，小 head 在计算后广播系数，跨 head 复用；扩展各阶段的源与目标互不重叠。
- 大块与较大系数批次存在 UB 取舍，使用按 shape 决定的容量，保持参数 1472B、单次启动以及 32B 跨核边界。

## 验证与限制

- 平台：CANN 9.0 / dav-2201，最终 15/15 Pass，所有 precision_ratio=1；实际硬件型号未单独披露。
- 实际内核 CPU 模型：230/230；连续布局额外 96/96；低 head 额外 144/144；768 组扩展访问非重叠检查。
- Host：1,812,272 种配置检查覆盖、容量、32B 核边界和 64 位地址，7 个官方文件逐字节一致。
- 数值：17,000,008 个角度扫描，最大绝对误差 sin 2.54e-7、cos 2.02e-7；这是实测覆盖，不是所有浮点输入的形式化证明。
- 本地 NumPy 2.4.4 power 与 host powf 的舍入差异仍有 107/230 个严格诊断失败，未修改 golden 或放宽阈值。
- CPU 模型不模拟异步设备行为；本地没有 CANN/NPU，独立 NPU runner 仍未实机验证。上述平台通过来自真实在线评测。
- 每个性能候选只做了一次正式平台提交，微小差异可能包含测量噪声；不把来源代码指令数下降直接当作 NPU 加速倍数。
